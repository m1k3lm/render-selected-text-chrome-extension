🎯 How to Use This Demo

  1. Make sure the Render Selected Text extension is installed and enabled
  2. Select any code block below (click and drag to select the text)
  3. Right-click on the selected text
  4. Choose Render selected text from the context menu
  5. Enjoy the beautiful visualization! Press ESC to close
